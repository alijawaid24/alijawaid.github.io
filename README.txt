ALI JAWAID — ACADEMIC & PROFESSIONAL PORTFOLIO

This is the complete static website package for: https://alijawaid24.github.io/

CONTENTS
- index.html: responsive portfolio website
- assets/: profile portrait, certificate images and observatory photographs
- documents/: original NASA ARSET Remote Sensing certificate, Sagan Summer Workshop confirmation letter, and German A1/A2 certificate PDFs
- sitemap.xml and robots.txt: basic search-engine discovery files

PUBLISH ON GITHUB PAGES
1. Open the public repository named alijawaid24.github.io.
2. Choose Add file > Upload files.
3. Extract this ZIP on your computer. Open the extracted folder.
4. Upload the CONTENTS of the extracted folder (index.html, assets folder, documents folder, sitemap.xml, robots.txt, README.txt) into the repository root. Do not upload the ZIP alone.
5. Scroll down and click Commit changes.
6. In repository Settings > Pages, ensure Deploy from a branch is selected, branch main, folder /(root), then Save.
7. Wait for the GitHub Pages deployment to complete. Website URL: https://alijawaid24.github.io/

NOTES
- Keep all folder names and file paths unchanged; the HTML uses relative paths.
- This package is prepared for publication but is not itself published until uploaded and deployed.
- Search engines may take time to index the site; ranking is not guaranteed.
- Personal phone number and residential address are not displayed on the public site.
